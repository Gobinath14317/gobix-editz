# GobiX Editz Portfolio Website

## Included
- Responsive neon-cyan portfolio website
- Services, portfolio gallery, pricing and contact sections
- YouTube, Instagram and GitHub links
- Mobile navigation

## Before publishing
1. Open `index.html` and replace the four portfolio sample slots with links/screenshots of your own completed work.
2. Confirm the starting prices and contact links are still correct.
3. Keep client contact through your public creator account; don't publish personal phone, address or private details.

## Publish with GitHub Pages
1. Open your existing GitHub Pages repository.
2. Back up the current site files.
3. Upload this `index.html` to the repository root, replacing the old homepage only if you want this new design to become the live site.
4. Commit the change and check the Pages URL after deployment.

The website is a starter template. It has not been published or connected to a payment system.
